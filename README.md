# Namekujis Borderlesswindow

**v0.1.0はWindows 11 x64向けの試作版です。** ウィンドウ表示のゲームを、選んだモニターに縦横比を保ったボーダレス全画面として拡大します。余白は黒帯になり、デスクトップの解像度は変更しません。すべてのゲームでの動作は保証していません。排他的フルスクリーンでしか動かないゲームは対象外です。

## ダウンロード

[Namekujis.Borderlesswindow-v0.1.0-win-x64.exe](https://github.com/UsumebiNamekuji/Namekujis-Borderlesswindow/releases/download/v0.1.0/Namekujis.Borderlesswindow-v0.1.0-win-x64.exe)

Releaseの**Assetsに添付された.exe**をダウンロードしてください。GitHubが自動生成する「Source code (zip)」には実行ファイルは含まれません。.NETランタイムの別途インストールは不要です。起動時に内部の一部ファイルを一時フォルダーへ展開する場合があります。

## 使い方

1. ゲームをウィンドウ表示で起動します。
2. ダウンロードした.exeを起動し、一覧からゲームのウィンドウを選びます。見つからないときは「ウィンドウ一覧を更新」を押してください。
3. 表示先のモニターを選び、「開始」を押します。
4. 解除するときは **Ctrl＋Shift＋F12** を押すか、設定画面の「解除」を押します。映像上の解除ボタンは設定で表示できます。解除後もゲームは終了せず、開始前の位置とサイズへ戻ります。
5. 使い終わったら設定画面を閉じます。表示中に閉じた場合も解除してから終了します。

解除キーは設定画面でCtrl・Shift・AltとF1～F12から変更できます。キーの登録に失敗した場合は開始しません。マウス固定は初期状態でオフです。設定画面へはAlt＋Tabなどで切り替えられます。

設定は `%LOCALAPPDATA%\Namekujis Borderlesswindow\settings.json` に保存します。初期値に戻すにはソフトを終了してからこのファイルを削除してください。保存したモニターが見つからない場合は、表示先を選び直してください。

## 確認状況と既知の制約

- v0.1.0の単体.exeはWindows 11上で起動を確認しました。試験用ウィンドウでは、対象選択、開始、対象のフォーカス維持、解除キーによる復帰を確認しました。
- RPGツクール製ゲーム、Sekiro、その他の実ゲームは未検証です。サブモニター、異なるDPI、ゲームパッド操作、実ゲームでのマウス操作と映像の動作も未確認です。
- 映像はWindowsのDWM縮小画像を使います。ゲームによっては黒画面や映像停止が起きる可能性があります。
- マウス操作はWindowsの通常のマウスメッセージで伝えます。Raw Input、DirectInput、カーソル位置の直接取得を使うゲームでは、移動、クリック、長押し、ドラッグ、ホイールが正しく動かない場合があります。管理者権限で起動したゲームへの入力も失敗する場合があります。
- 元のゲームウィンドウが表示先モニターより大きい場合は開始できません。ゲーム自身が別アプリへの切り替え時に一時停止する動作は変更しません。
- 強制終了や電源断では、ゲームウィンドウの位置や状態の復元を保証できません。入力遅延や性能は未測定です。

不具合を報告する際は、ゲーム名と版、Windowsの版、モニターの配置・解像度・DPI、再現手順、期待した結果、実際の結果、可能なら画面の記録を添えてください。
