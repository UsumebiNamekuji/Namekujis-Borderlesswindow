# Namekujis Borderlesswindow v0.2.0

ウィンドウ表示のゲームを、選んだモニターで縦横比を保ったボーダレスフルスクリーンとして表示するWindows 11向けの**試作版**です。余白は黒帯になります。デスクトップの解像度やリフレッシュレートは変更しません。

## ダウンロード

[Windows 11 x64用の単体.exeをダウンロード](https://github.com/UsumebiNamekuji/Namekujis-Borderlesswindow/releases/download/v0.2.0/Namekujis.Borderlesswindow-v0.2.0-win-x64.exe)

[v0.2.0のReleaseページ](https://github.com/UsumebiNamekuji/Namekujis-Borderlesswindow/releases/tag/v0.2.0)からも取得できます。**Assetsの`Namekujis.Borderlesswindow-v0.2.0-win-x64.exe`を選んでください。** GitHubが表示する「Source code (zip / tar.gz)」には実行ファイルは含まれません。

.NETランタイムの追加インストールや、配布DLLの用意は不要です。実行時には一時フォルダーへの内部ファイル展開と、設定ファイルの作成が行われます。

## 使い方

1. ゲームを**ウィンドウ表示**で起動します。
2. ダウンロードした.exeを起動し、「起動中のウィンドウ」からゲームを選びます。同じタイトルでもPIDとHWNDで区別できます。最小化した通常ウィンドウも表示します。
3. 「共通設定」で表示先モニターを選び、「開始」を押します。元のゲームウィンドウは表示先へ移り、その上に拡大映像を表示します。
4. 完全解除するときは、新規設定の初期値 **Ctrl＋Shift＋F11** を同時に押します。一覧の適用中・一時解除中の行を選んで「解除」を押すこともできます。映像上の解除ボタンは共通設定で表示できます。初期状態は非表示です。
5. 本ソフトを閉じると、補助表示を完全解除してから終了します。ゲームは終了しません。

「マウスをゲーム映像内に固定」は初期状態でオフです。オンにすると黒帯を除く映像内に固定し、一時解除・完全解除時に解放します。共通設定は完全解除後に変更できます。

### .exeの登録と自動適用

一覧でゲームを選び、「選択した.exeを登録」を押すと、そのウィンドウを所有する実行ファイルを登録できます。登録済みのゲームは、本ソフトの起動中に通常どおり起動し、ゲームへ切り替えると自動適用します。登録せずに手動の「開始」を使うこともできます。

登録は実行ファイルのフルパスを使い、選んだ画面の種類を識別する情報（ウィンドウクラス）も保存します。ファイル名が同じでも別の場所の.exeには適用しません。ゲームを移動した場合や、更新などで画面の種類が変わって自動適用されなくなった場合は、ゲーム本体を選んで登録し直すか、手動で開始してください。登録済みの行では、同じボタンから登録を解除できます。ランチャーではなく、実際にゲームを表示しているウィンドウを選んでください。

自動適用は別アプリの操作を奪わず、同時に1つのウィンドウだけを扱います。複数の対象候補がある場合や、初期化中・設定用の画面と判断された場合は自動適用せず、一覧から手動で開始できます。本ソフトにはゲームを起動する機能や、終了後に残る監視機能はありません。

### 一時解除と完全解除

Winキーでスタートメニューを開く、Alt＋Tabで別アプリへ移るなど、対象ゲームから切り替えると**一時解除中**になります。デスクトップを通常操作でき、対象ゲームへ戻ると同じモニターへ自動復帰します。ゲーム自身の、フォーカスを失ったときの停止動作は変えません。

解除ショートカットや「解除」は**完全解除**です。開始前の位置・サイズ・表示状態へ戻り、そのゲームの現在の起動中は自動再適用を抑止します。同じプロセス内でウィンドウが作り直された場合も抑止を維持します。「開始」で手動再適用でき、ゲームを終了して再起動した場合は再び自動適用できます。.exeの登録情報は消えません。

対象終了、表示先モニターの消失、処理失敗では補助表示を解除します。自動復帰や開始を繰り返し試すことはありません。対象とモニターを確認してから、必要に応じて手動で開始してください。

### 解除ショートカットの設定

「解除ショートカット」の「＋ 追加」または「変更」を開き、「キーを取り込む」を押して、使いたいキーを同時に押して離し、「確定」してください。「× 削除」で削除できます。有効な組み合わせを最低1つ残す必要があります。

一般キーやSpaceを含む複数の組み合わせを保存でき、**A＋Space＋R**も設定できます。すべてのキーを同時に押した状態になった瞬間に1回発動し、押す順序は問いません。順番に1つずつ押して離す操作では発動しません。取り込み中は解除判定を止めます。

キー入力は遮断しないため、完全解除の直前にゲームへ構成キーの入力が伝わる場合があります。ゲーム操作と重なりにくい組み合わせを選んでください。Winキー、F12、アプリ切り替えなどの予約操作と重なる組み合わせ、一部の特殊キーは理由を表示して受け付けません。他のソフトが同じキーを使う場合は、両方が反応することがあります。

## 設定保存とv0.1.0からの移行

設定は `%LOCALAPPDATA%\Namekujis Borderlesswindow\settings.json` に保存します。共通設定、解除ショートカット、登録した.exeの情報を次回起動時にも復元します。初期化するには、本ソフトを閉じてからこのファイルを削除してください。登録情報も初期化されます。設定が読み取れない場合は初期値で起動します。保存したモニターが存在しない場合は、表示先を選び直してください。

v0.1.0のモニター・マウス設定と解除キーを読み込みます。以前のF12を含む解除キーは、使用できない登録として残し、通知とともにCtrl＋Shift＋F11を追加します。有効な以前の設定はそのまま利用できます。

## 対応範囲・既知の制約

- 対象はWindows 11 x64と、ウィンドウ表示できるゲームです。**すべてのゲームへの対応は保証しません。** 排他的フルスクリーンでしか動かないゲームは対象外です。
- 元のウィンドウが表示先モニターより大きい場合は開始できません。ゲームのウィンドウを小さくしてから試してください。
- ゲームや描画方式によって、黒画面・映像停止・画質の違いが生じる可能性があります。映像が止まった場合は解除ショートカットか設定画面から完全解除してください。
- マウス転送は通常のWindowsマウスメッセージを受け取るゲーム向けです。Raw Input、DirectInput、カーソル位置の直接取得を使うゲームでは、移動・クリック・ドラッグ・ホイールが一部または全部動かない場合があります。
- 管理者権限のゲームや保護されたプロセスでは、対象の識別・登録・入力転送が制限される場合があります。
- スプラッシュ画面や設定画面の判定は完全ではありません。誤った画面へ自動適用される場合は登録を解除し、ゲーム本体へ手動で開始してください。
- 強制終了や電源断では元ウィンドウの復元を保証できません。実行ファイルにコード署名はありません。

Windows 11の試験用ウィンドウで、単体.exeの起動、手動開始、登録した.exeへの自動適用と再起動後の登録保持、初期解除キー・A＋Space＋R・一覧の「解除」による完全解除、完全解除後の手動再適用、スタートメニューへの切り替え後の自動復帰、通常終了を確認しました。実ゲームへの対応確認ではありません。

RPGツクール作品、Sekiroを含む実ゲームでの互換性は未検証です。Winキーそのものの直接入力、画面でのキー取り込みの確定操作、サブモニター、負の座標・異なるDPI、ゲームパッド、モニター切断、実ゲームでのマウス操作、入力から表示までの遅延も未確認です。

## 短い確認手順と不具合報告

初めはセーブに支障がない場面で試してください。手動で開始し、映像・キー・マウス操作を確認した後、Winキーで一時解除してゲームへ戻り、完全解除で位置が戻ることを確認します。.exeを登録した場合は、ゲームを再起動して自動適用と、完全解除後に勝手に再適用しないことも試してください。

[Issues](https://github.com/UsumebiNamekuji/Namekujis-Borderlesswindow/issues)へ、ソフトの版、ゲーム名・版、Windowsの版、モニターの配置・解像度・DPI、入力機器、再現手順、期待した結果と実際の結果を記載してください。一時解除か完全解除か、手動開始か自動適用か、ゲーム再起動やウィンドウ再作成の有無も分かると確認しやすくなります。個人情報を含む設定ファイルをそのまま添付する必要はありません。
